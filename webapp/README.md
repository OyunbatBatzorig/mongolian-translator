# Хүний эрхийн орчуулагч, веб хувилбар (эхний, зөвхөн өөрийн компьютер дээр)

## Ажиллуулах

```bash
cd ~/mongolian-translator/webapp
../venv/bin/python create_admin.py таны@имэйл.mn      # зөвхөн анх удаа: админ үүсгэнэ
../venv/bin/python -m uvicorn main:app --port 8000
```

Дараа нь хөтөч дээрээ **http://localhost:8000** хаягийг нээнэ. Зогсоох бол терминал дээр `Ctrl+C` дарна.
Сервер асаад эхний 20–40 секундэд загвараа ачаална.

## Бүтэц

```
Хөтөч (templates/*.html + static/app.js)
   │  fetch('/api/translate')
   ▼
main.py (FastAPI) ── auth.py (нууц үг, нэвтрэлт)
   │                └ db.py (SQLite: users, sessions, usage, jobs)
   ▼
translator.py (NLLB загвар, GPU) ← documents.py (PDF/DOCX/TXT унших, DOCX бичих)
```

| Файл | Юу хийдэг вэ |
|---|---|
| `config.py` | **Бүх хязгаар энд байна**: `TEXT_LIMITS` (эрх бүрийн тэмдэгт), 20 хуудас, сард 1 файл, загварын зам |
| `main.py` | Хуудас болон API-ийн бүх хаяг (route), эрх шалгах, файлын дараалал |
| `auth.py` | Нууц үгийг PBKDF2-оор хувиргаж хадгалах, нэвтрэлтийн token, хэн орчуулах эрхтэйг шийдэх |
| `db.py` | Өгөгдлийн сангийн хүснэгтүүд (`instance/app.db`) |
| `translator.py` | Текстийг өгүүлбэрээр хувааж загвараар орчуулах |
| `documents.py` | Файлаас текст гаргах, хуудас тоолох, орчуулгыг .docx болгох |
| `templates/` | HTML хуудаснууд (нүүр, нэвтрэх, бүртгүүлэх, миний бүртгэл, админ) |
| `static/` | CSS загвар, JavaScript |

## Эрхийн төрөл

| Эрх | Текст (нэг удаад) | Файл (нэг нь 20 хуудас хүртэл) | Хэн |
|---|---|---|---|
| 1. Үнэгүй, бүртгэлгүй зочин | 1200 тэмдэгт | сард 1 | Хэн ч. Сарын файлыг cookie + IP хаягаар тоолно |
| 1. Үнэгүй, бүртгэлтэй | эхний 14 хоногт **5000**, дараа нь 1200 | сард 2 (+1) | Өөрөө бүртгүүлсэн хүн, эсвэл төлбөрийн хугацаа нь дууссан хүн |
| 2. Төлбөртэй | 5000 | сард 30 | Админ "Төлбөр сунгах" дарсан хүн. Хугацаа дуусахад автоматаар үнэгүй эрх рүү буцна |
| 3. Хувь нэмэр оруулагч | 5000 | сард 50 | Датасет өгсөн хүмүүс. Төлбөргүй, хугацаагүй, админ эрхийг нь өгнө/хасна |
| 4. Админ | 5000 | хязгааргүй | Та |

Бүх тоо `config.py`-ийн `TEXT_LIMITS`, `FILES_PER_MONTH`, `TRIAL_DAYS` мөрөнд байна.
Зочин минутад 20-оос олон текст орчуулах хүсэлт илгээж чадахгүй (`GUEST_REQUESTS_PER_MINUTE`).

Датасет өгсөн хүнийг нэмэх: **Админ самбар → "Шинэ хэрэглэгч нэмэх"** хэсэгт эрхийг нь "Хувь нэмэр оруулагч" болгоно.
Түр нууц үгээ тэр хүнд өөрөө дамжуулна.

## Имэйл, OTP код

Бүртгүүлэх (имэйл → код → нууц үг), имэйл солих, нууц үг солих, нууц үг мартсан үед 6 оронтой
код имэйлээр очно (10 минут хүчинтэй, 5 удаа буруу оруулбал хүчингүй, минутад 1 код).

- **Одоо (SMTP тохируулаагүй)**: имэйл илгээхгүй, кодыг **серверийн терминал** дээр
  `===== [ИМЭЙЛ, туршилтын горим] =====` гэж хэвлэнэ.
- **Жинхэнэ имэйл илгээх**: Gmail дээр 2 шаттай баталгаажуулалт асаагаад "App password" үүсгэнэ, дараа нь:
  ```bash
  SMTP_HOST=smtp.gmail.com SMTP_PORT=587 SMTP_USER=таны@gmail.com SMTP_PASSWORD=<app password> \
  SMTP_FROM=таны@gmail.com ../venv/bin/python -m uvicorn main:app --port 8000
  ```
- Нууц үгийг шифрлэж хадгалдаг тул хэн ч (админ ч) харах боломжгүй, зөвхөн сольж болно.

## Үнэ ба төлбөр

- Үнэ: `config.py` → `MONTHLY_PRICE` (19,900₮), `QUARTERLY_DISCOUNT` (20% → 47,700₮/3 сар). "Байгууллага" = зөвхөн байгууллагын нэр дээрх нэхэмжлэх, И-баримт (нэг захиалга = нэг хэрэглэгч).
- Төлбөрийн мэдээлэл: `config.py` → `PAYMENT` (⚠️ одоо ЖИШЭЭ утгатай: банк, данс, IBAN, хүлээн авагч, утас).
- Урсгал: `/pricing` → `/buy` (багц → мэдээлэл → төлбөр) → `/orders/<HR-код>` (данс/QPay, "Төлсөн" товч)
  → Админ самбар → "Захиалга" таб → "Баталгаажуулах" → эрх автоматаар сунгагдана.
- QPay: одоогоор QR-ийн оронд түр зураг. QPay merchant гэрээ хийж API түлхүүр авсны дараа
  `billing.py`-д QPay invoice үүсгэх, төлбөрийн callback-аар автоматаар баталгаажуулах кодыг нэмнэ.

## Нууцлал (хүний эрхийн текст тул чухал)

- Орчуулсан **текстийг хадгалдаггүй**. Зөвхөн тэмдэгт, хуудасны тоог бүртгэдэг.
- Илгээсэн файлыг орчуулсны дараа шууд устгадаг. Орчуулгын үр дүн 24 цагийн дараа устна.
- Нууц үгийг шууд биш, буцааж тайлж болохгүй хэлбэрээр хадгалдаг.
- `instance/` хавтас (хэрэглэгчдийн өгөгдөл) git-д орохгүй (`.gitignore`).

## Интернэтэд гаргахаас өмнө хийх зүйлс

1. **HTTPS** (Let's Encrypt), домэйн нэр. HTTPS-гүйгээр нууц үг ил дамжина.
2. **Төлбөр**: одоогоор админ гараар "Төлбөр сунгах" дардаг. Дараа нь QPay эсвэл банкны API холбоно.
3. Нууц үг сэргээх (имэйл илгээх), бүртгэлийн имэйл баталгаажуулалт.
4. Олон зэрэг хэрэглэгч ирвэл: нэг GPU нэг удаад нэг хүсэлт боловсруулдаг. Дарааллын систем эсвэл хүчтэй сервер хэрэгтэй.
5. Хэт олон хүсэлт илгээхээс хамгаалах хязгаар (rate limit), нэвтрэх оролдлогын хязгаар.
6. **Монгол → Англи** загвар: `config.py`-ийн `MODEL_MN_EN` зам дээр загвар гармагц сонголт автоматаар идэвхжинэ.

## Загвар солих

`config.py` дахь `MODELS["en-mn"]` замыг өөрчилнө. Эсвэл серверийг ингэж асаана:

```bash
MODEL_EN_MN=../benchmark/nllb_v2_laws/final ../venv/bin/python -m uvicorn main:app --port 8000
```

## Интернэтэд үнэгүй хувилбарыг нээх (туршилт)

```bash
cd ~/mongolian-translator && ./start_public.sh
```

- `PUBLIC_SIMPLE=1` горимоор 8080 порт дээр тусдаа сервер асна (`webapp/public_mode.py`).
  Нүүр хуудас = бүртгэлгүй орчуулагч; нэвтрэх, бүртгүүлэх, төлбөр, админ, `/docs` бүгд нүүр рүү буцна.
- Хязгаар (IP тус бүр): текст минутад 10, өдөрт 300 (5000 тэмдэгт хүртэл); файл цагт 5; дараалал 20-оос урт бол түр хүлээлгэнэ.
- Текстийг хадгалахгүй, лог-д бичихгүй. Орчуулсан файлыг 2 цагийн дараа устгана.
- Cloudflare quick tunnel `https://....trycloudflare.com` хаяг өгнө (асах бүрт өөрчлөгдөнө). Домэйн авсны дараа named tunnel болгоно.
- Таны бүрэн хувилбар (8000 порт) зөвхөн өөрийн компьютер дээр үлдэнэ.
